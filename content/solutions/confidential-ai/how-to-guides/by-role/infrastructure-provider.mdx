As the infrastructure provider, you run the servers the workload's TEE lives on. You prepare them, enrol them in CCM so they can attest, and install the runtime. You never see the model or the data. You only need the servers to be genuine and correctly configured.

## Your tasks

| Day | Task |
|---|---|
| 0 | [Prepare the servers](../day-0-plan-and-prepare/prepare-the-servers.mdx#prepare-the-servers) |
| 0 | [Enrol the servers](../day-0-plan-and-prepare/prepare-the-servers.mdx#enrol-the-servers) with the consumer's join token |
| 0 | [Install the runtime](../day-0-plan-and-prepare/prepare-the-servers.mdx#install-the-runtime) |
| 2 | [Upgrade the servers](../day-2-operate/update-the-workload-tcb.mdx#upgrade-the-servers) once the new build is approved, and [update the hosts](../day-2-operate/update-the-workload-tcb.mdx#update-the-hosts) |
