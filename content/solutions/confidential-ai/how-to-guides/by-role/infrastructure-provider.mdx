As the infrastructure provider, you run the hardware the workload's TEE lives on. You prepare the host, enrol it in CCM so it can attest, and install the runtime. You never see the model or the data; you only need the host to be genuine and correctly configured.

| Day | Task |
|---|---|
| 0 | [Prepare the host](../day-0-plan-and-prepare/prepare-gpu-nodes.mdx#prepare-the-host) |
| 0 | [Enrol the node](../day-0-plan-and-prepare/prepare-gpu-nodes.mdx#enrol-the-node) with the consumer's join token |
| 0 | [Install the runtime](../day-0-plan-and-prepare/prepare-gpu-nodes.mdx#install-the-runtime) |
| 2 | [Upgrade the runtime](../day-2-operate/update-the-model-or-runtime.mdx#upgrade-the-runtime) and [update the hosts](../day-2-operate/update-the-model-or-runtime.mdx#update-the-hosts) |

The [end-to-end guides](../end-to-end/vendor-to-customer.mdx) show where these fit among the other roles' tasks.
