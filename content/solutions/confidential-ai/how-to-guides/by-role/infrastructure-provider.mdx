As the infrastructure provider, you run the infrastructure the workload's TEE lives on. You prepare the hosts, enroll them in CCM so they can attest, and install the runtime. You never see the model or the data. You only need the hosts to be genuine and correctly configured.

## Your tasks

| Day | Task |
|---|---|
| 0 | [Prepare the infrastructure](../day-0-plan-and-prepare/prepare-the-infrastructure.mdx#prepare-the-hosts) |
| 0 | [Enroll the hosts](../day-0-plan-and-prepare/prepare-the-infrastructure.mdx#enroll-the-hosts) with the consumer's join token |
| 0 | [Install the runtime](../day-0-plan-and-prepare/prepare-the-infrastructure.mdx#install-the-runtime) |
| 2 | [Upgrade the infrastructure](../day-2-operate/update-the-workload-tcb.mdx#upgrade-the-infrastructure) once the new build is approved, and [update the hosts](../day-2-operate/update-the-workload-tcb.mdx#update-the-hosts) |
