As the model consumer, you run the model and send it your data. You own the CCM account the nodes belong to, run the workload, and check that it really runs in a TEE before you trust it with anything.

| Day | Task |
|---|---|
| 0 | [Plan the deployment](../day-0-plan-and-prepare/plan-a-deployment.mdx) with the model owner |
| 0 | [Set up CCM](../day-0-plan-and-prepare/prepare-gpu-nodes.mdx#set-up-ccm): a group, the join token and the zone CA |
| 1 | [Share the model](../day-1-deploy/share-the-model.mdx) through a shared workflow, as the consumer |
| 1 | [Deploy and verify](../day-1-deploy/deploy-and-verify.mdx), then connect clients |
| 2 | [Update the model or the runtime](../day-2-operate/update-the-model-or-runtime.mdx) |
| 2 | [Audit and revoke access](../day-2-operate/audit-and-revoke-access.mdx) |

The [end-to-end guides](../end-to-end/vendor-to-customer.mdx) show where these fit among the other roles' tasks.
