An enterprise runs a public open-source model. The weights are already public, so they need no protection. What matters is the data, meaning the prompts, the documents the model reads and the answers it returns. Attestation also proves that the expected model and code are running, not a modified copy.

## What is protected

- **Prompts, data and answers.** The NCP's hosts and administrators cannot read them while the model processes them.
- **The integrity of the workload.** CCM issues a certificate only when the measurement matches an approved model. The enterprise, and any service that checks the certificate, know exactly which model and code are running.

## Keys

The workload always attests to CCM and gets a certificate. There is no model encryption key, but the workload can get a key from DSM whenever it needs one, for example to open encrypted storage that holds documents for retrieval.
