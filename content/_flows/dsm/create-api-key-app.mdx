{/* Shared flow (D16): create a DSM app that authenticates with an API key.
    Props: name, the app name to suggest (default model-encryption);
    group (default model-keys). */}

<Walkthrough label="Create an API key app">
<Step
  title="Open Apps"
  image={require('../img/dsm-apps.webp').default}
  width={1568}
  height={501}
  marks={[[94.0, 20.8, 5.4, 8.4]]}
  alt="The Apps page in DSM, with ADD APP outlined">

In DSM, go to **Apps** and click **ADD APP**.

</Step>
<Step
  title="Name the app"
  image={require('../img/dsm-app-apikey.webp').default}
  width={1568}
  height={436}
  marks={[[1.6, 8.5, 48.3, 14.4], [50.4, 11.5, 29.5, 11.5], [1.7, 51.8, 8.4, 13.3]]}
  alt="The new app form, with the app name, the interface and API Key outlined">

Enter the **App name**, such as <code>{props.name ?? 'model-encryption'}</code>, set **Interface** to **REST API**, and keep **Authentication method** as **API Key**.

</Step>
<Step
  title="Assign the group and save"
  image={require('../img/dsm-app-groups.webp').default}
  width={1568}
  height={648}
  marks={[[50.5, 8.8, 46.6, 12.5], [91.2, 90.4, 6.0, 7.7]]}
  alt="The groups the app is assigned to, with the group and SAVE outlined">

Under **Assigning the new app to groups**, click the group, such as <code>{props.group ?? 'model-keys'}</code>, so that it moves to the list on the right. Click **SAVE**.

</Step>
<Step
  title="Copy the API key"
  image={require('../img/dsm-app-encrypt-page.webp').default}
  width={1568}
  height={711}
  marks={[[2.9, 66.4, 17.5, 6.3]]}
  alt="The new app, with VIEW API KEY DETAILS outlined">

The app opens. Click **VIEW API KEY DETAILS** and copy the API key. Keep it secret.

</Step>
</Walkthrough>
