{/* Shared flow (D16): create a workflow in one CCM account, approve it, and
    find the application configuration ID. */}

<Walkthrough label="Create a workflow">
<Step
  title="Open Workflows"
  image={require('../img/ccm-workflows.webp').default}
  width={1568}
  height={665}
  marks={[[0.4, 23.8, 12.2, 5.2], [90.1, 16.5, 8.1, 4.8]]}
  alt="CCM's Workflows page, with Workflows and ADD WORKFLOW outlined">

In CCM, go to **Workflows** and click **ADD WORKFLOW**.

</Step>
<Step
  title="Name the workflow"
  image={require('../img/ccm-workflow-add.webp').default}
  width={1568}
  height={665}
  marks={[[28.4, 39.7, 20.9, 6.9], [49.8, 39.7, 20.9, 6.9], [33.8, 61.6, 8.1, 4.4]]}
  alt="The Add Workflow dialog, with the name, the group and ADD WORKFLOW outlined">

Enter a **Name**, such as `model-server-workflow`, select the **Group**, and click **ADD WORKFLOW**. The workflow opens as a draft.

</Step>
<Step
  title="Add an application node"
  image={require('../img/ccm-wf-empty.webp').default}
  width={1568}
  height={665}
  marks={[[51.4, 83.9, 3.0, 6.6]]}
  alt="The empty draft graph, with the Application icon in the bar outlined">

Drag the **Application** icon from the bar under the graph onto the graph.

</Step>
<Step
  title="Open the application picker"
  image={require('../img/ccm-wf-node.webp').default}
  width={1568}
  height={665}
  marks={[[55.6, 49.0, 12.2, 7.2]]}
  alt="The new node on the graph, with ADD APPLICATION outlined">

Click **ADD APPLICATION** on the new node.

</Step>
<Step
  title="Select the application"
  image={require('../img/ccm-wf-select-app.webp').default}
  width={1568}
  height={665}
  marks={[[22.5, 58.0, 74.2, 6.6], [27.0, 90.4, 5.3, 4.4]]}
  alt="The application picker, with the application and PROCEED outlined">

Select the application and click **PROCEED**.

</Step>
<Step
  title="Select the build"
  image={require('../img/ccm-wf-select-build.webp').default}
  width={1568}
  height={665}
  marks={[[21.6, 40.0, 42.0, 6.4], [27.0, 90.4, 5.3, 4.4]]}
  alt="The build picker, with the build and PROCEED outlined">

Select the build and click **PROCEED**.

</Step>
<Step
  title="Select the configuration"
  image={require('../img/ccm-wf-select-config.webp').default}
  width={1568}
  height={665}
  marks={[[22.5, 64.1, 74.2, 6.6], [27.0, 90.4, 8.4, 4.4]]}
  alt="The configuration picker, with the configuration and ADD APPLICATION outlined">

Select the application configuration, or click **CREATE NEW CONFIGURATION**, and click **ADD APPLICATION**.

</Step>
<Step
  title="Save the draft"
  image={require('../img/ccm-wf-canvas.webp').default}
  width={1568}
  height={665}
  marks={[[55.5, 65.6, 12.1, 7.2], [75.7, 16.4, 6.3, 4.9]]}
  alt="The draft workflow with the application node and SAVE DRAFT outlined">

The node shows the application. Click **SAVE DRAFT**, and wait for the confirmation that the workflow was saved. Without it, the node isn't kept, and requesting approval fails with "can't create empty workflow".

</Step>
<Step
  title="Request approval"
  image={require('../img/ccm-wf-request.webp').default}
  width={1568}
  height={665}
  marks={[[41.5, 57.9, 9.4, 5.0]]}
  alt="The confirmation dialog, with REQUEST APPROVAL outlined">

Click **SAVE AND REQUEST APPROVAL**, and confirm with **REQUEST APPROVAL**.

</Step>
<Step
  title="Open the pending workflow"
  image={require('../img/ccm-wf-pending.webp').default}
  width={1568}
  height={665}
  marks={[[22.0, 36.2, 11.6, 6.2], [14.3, 51.3, 83.6, 7.4]]}
  alt="The Pending Approval tab, with the workflow outlined">

A reviewer goes to **Workflows** > **Pending Approval** and clicks the workflow.

</Step>
<Step
  title="Approve"
  image={require('../img/ccm-wf-approve.webp').default}
  width={1568}
  height={665}
  marks={[[19.6, 25.6, 60.1, 41.4], [24.9, 82.7, 5.3, 4.6]]}
  alt="The approval request, with the graph and APPROVE outlined">

Check the graph and click **APPROVE**.

</Step>
<Step
  title="Open the approved workflow"
  image={require('../img/ccm-wf-approved.webp').default}
  width={1568}
  height={665}
  marks={[[13.8, 36.2, 8.5, 6.2], [88.8, 52.4, 6.0, 5.0]]}
  alt="The Approved workflows, with VIEW DETAILS outlined">

The workflow moves to **Approved**. Click **VIEW DETAILS** on it.

</Step>
<Step
  title="Open the application's properties"
  image={require('../img/ccm-wf-final.webp').default}
  width={1568}
  height={665}
  marks={[[23.9, 48.3, 2.0, 4.8]]}
  alt="The approved workflow, with the information icon on the application's node outlined">

Click the information icon on the application's node.

</Step>
<Step
  title="Copy the application configuration ID"
  image={require('../img/ccm-wf-config-id.webp').default}
  width={1568}
  height={665}
  marks={[[51.6, 92.0, 31.6, 7.6]]}
  alt="The application properties, with the application configuration ID outlined">

Copy the **Application configuration ID**, the runtime configuration hash. The workload passes it when it starts.

</Step>
</Walkthrough>
