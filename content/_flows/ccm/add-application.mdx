    Props: runtime, "cc" (default) or "eos"; name, group and domain to suggest. */}

<Walkthrough label="Add the application">
<Step
  title="Open Applications"
  image={require('../img/ccm-apps.webp').default}
  width={1568}
  height={665}
  marks={[[0.4, 44.6, 12.2, 5.4], [88.8, 33.7, 8.4, 4.8]]}
  alt="CCM's Applications page, with Applications and ADD APPLICATION outlined">

In CCM, go to **Applications** and click **ADD APPLICATION**.

</Step>
<Step
  title="Choose the type and platform"
  image={props.runtime === 'eos' ? require('../img/ccm-app-type-eos.webp').default : require('../img/ccm-app-type-coco.webp').default}
  width={1568}
  height={665}
  marks={props.runtime === 'eos' ? [[22.8, 24.1, 14.6, 13.8], [53.4, 63.0, 14.6, 13.8], [27.9, 82.3, 3.6, 4.4]] : [[37.9, 39.6, 14.6, 13.8], [37.9, 63.0, 14.6, 13.8], [27.9, 82.3, 3.6, 4.4]]}
  alt="The Add Application dialog, with the application type, Intel TDX and NEXT outlined">

Select {props.runtime === 'eos' ? <strong>Confidential Container - Enclave OS</strong> : <strong>Confidential Container - CoCo</strong>}, then the platform, such as **Intel TDX**, and click **NEXT**.

</Step>
<Step
  title="Enter the details"
  image={props.runtime === 'eos' ? require('../img/ccm-app-details-eos.webp').default : require('../img/ccm-app-details.webp').default}
  width={1568}
  height={665}
  marks={[[22.6, 36.4, 24.8, 7.8], [22.6, 48.3, 24.8, 8.0]]}
  alt="The application details, with the name and the group outlined">

Enter the **Application name**, such as <code>{props.name ?? 'model-server'}</code>, a **Description** if you like, and select the **Group**, such as <code>{props.group ?? 'model-serving'}</code>. Under **Certificate Configuration**, click **ADD CERTIFICATE**.

</Step>
<Step
  title="Add the certificate domain"
  image={require('../img/ccm-app-certificate.webp').default}
  width={1568}
  height={665}
  marks={[[22.6, 46.9, 24.8, 7.5], [22.6, 64.7, 50.4, 7.5], [32.0, 86.9, 8.4, 4.6]]}
  alt="The certificate configuration, with the domain, the type and the ADD APPLICATION button outlined">

Enter the **Domain** of the workload's certificate, such as <code>{props.domain ?? 'model.northwind.example'}</code>. Leave **Type** as **Certificate Issued by Confidential Computing Manager**, and click **ADD APPLICATION**.

</Step>
</Walkthrough>
