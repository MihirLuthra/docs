## Before you begin

- A [prepared host](prepare-a-host.mdx).
- The application [registered in CCM](../../ccm/applications/register-an-application.mdx), its build approved.

## Run the image

1. In CCM, open the application's configuration and copy its **Runtime configuration hash**.
2. Start the converted image:

   ```bash
   docker run --privileged --runtime=runc \
     -e APPCONFIG_ID=<RUNTIME_CONFIG_HASH> \
     -e GPU_COUNT=<GPU_COUNT> \
     <CONVERTED_IMAGE>:<TAG>
   ```

   - `<RUNTIME_CONFIG_HASH>`: the hash from step 1.
   - `<GPU_COUNT>`: how many GPUs to give the workload. To pick specific GPUs, set `TDX_GPU_BDF` instead, to a comma-separated list of their PCI addresses.
   - `<CONVERTED_IMAGE>:<TAG>`: the converted image.

   Without GPUs, leave out `GPU_COUNT`.
