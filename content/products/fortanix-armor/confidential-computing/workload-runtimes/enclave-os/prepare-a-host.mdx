## Pass GPUs through

Skip this without GPUs. A GPU can be passed through to only one TEE at a time.

1. Find the NVIDIA GPUs and check their driver.

   ```bash
   lspci -D -d 10de:
   lspci -nnk -d 10de:
   ```

2. If a GPU doesn't show `Kernel driver in use: vfio-pci`, bind it, as root.

   ```bash
   sudo modprobe vfio-pci
   echo <VENDOR_ID> <DEVICE_ID> | sudo tee /sys/bus/pci/drivers/vfio-pci/new_id
   ```

   - `<VENDOR_ID> <DEVICE_ID>` come from the `lspci -nnk` output, for example `10de 2330`.

## Verify

- `lspci -nnk -d 10de:` shows `Kernel driver in use: vfio-pci` for each GPU.
