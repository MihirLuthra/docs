A node enrolled in CCM can attest, so the workloads on it can get certificates. The node agent attests the host to CCM and passes attestation requests and certificates between the workloads and CCM.

## Before you begin

- A bare-metal host with an Intel TDX CPU.
- A CCM account.
- Outbound access from the host to `download.01.org`, `api.trustedservices.intel.com` and CCM.

## Prepare the host

1. In the BIOS, enable Intel TDX and disable simultaneous multithreading (SMT). With SMT on, a TEE fails to start with `fw_error=7 'Policy is not allowed'`.
2. Install the Intel SGX registration agent.

   ```bash
   wget -q https://download.01.org/intel-sgx/sgx_repo/ubuntu/intel-sgx-deb.key -O /tmp/intel-sgx.key
   sudo gpg --dearmor -o /usr/share/keyrings/intel-sgx-keyring.gpg /tmp/intel-sgx.key
   echo "deb [signed-by=/usr/share/keyrings/intel-sgx-keyring.gpg] https://download.01.org/intel-sgx/sgx_repo/ubuntu noble main" \
     | sudo tee /etc/apt/sources.list.d/intel-sgx.list
   sudo apt-get update
   sudo apt-get install -y sgx-ra-service
   ```

3. Register the platform with Intel. Either enable **SGX Auto MP Registration** in the BIOS and reboot, or register manually.

   ```bash
   /opt/intel/sgx-ra-service/mpa_manage -get_platform_manifest platform_manifest
   curl -H "Content-Type: application/octet-stream" --data-binary @platform_manifest \
     -X POST "https://api.trustedservices.intel.com/sgx/registration/v1/platform"
   ```

   A manual registration returns `201 Created`.

4. Check the registration.

   ```bash
   cat /var/log/mpa_registration.log
   ```

   It shows `Registration Flow - PLATFORM_ESTABLISHMENT passed successfully` or `Registration Flow - TCB_RECOVERY passed successfully`.

If someone else runs the host, send them the join token over a channel you trust.

## Install the node agent

1. Download `TDX-Node-Agent-installer.tar.gz` from the link in **Enroll Compute Node**, and extract it.

   ```bash
   tar -zxvf TDX-Node-Agent-installer.tar.gz
   cd em-agent-installer-tdx
   ```

2. Run the installer with the join token.

   ```bash
   sudo bash installer.sh <JOIN_TOKEN>
   ```

   - `<JOIN_TOKEN>` is the join token from CCM.

## Verify

- `systemctl status em-agent` shows the agent running. For its log, run `journalctl -xe | grep em-agent`.
- The node is listed under **Infrastructure** > **COMPUTE NODES** > **Intel TDX**. Its labels, such as `fortanix.cloud/node-tee-type`, describe the host.
